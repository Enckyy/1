# МОС + Мореходная астрономия

Готовый статический сайт для GitHub Pages.

## Загрузка на GitHub

Загрузите **все файлы из этой папки в корень репозитория**. В корне репозитория должен находиться `index.html`.

Структура корня:
- `index.html` — главная страница
- `mos.html` — МОС
- `astronomy.html` — мореходная астрономия
- `mae-2025.rar` — встроенные данные МАЕ-2025
- `sw.js` — Service Worker
- `manifest.webmanifest` — PWA-манифест
- `math-standard.woff2` — шрифт математических символов
- `icon-192.png`, `icon-512.png` — иконки

## GitHub Pages

Settings → Pages → Deploy from a branch → выберите нужную ветку и `/ (root)`.

После публикации откройте адрес GitHub Pages. Не создавайте дополнительную папку `MOS_MAE_Merged`: `index.html` должен быть непосредственно в корне выбранного источника публикации.


MAE-2025: встроенный RAR5 распаковывается в браузере через pinned libarchive-wasm 1.2.0; отдельная установка ПО не требуется.
